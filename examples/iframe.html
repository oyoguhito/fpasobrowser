Same-origin iframe input test

This local page checks the embedded-document path used by pages that put a form inside an iframe. It does not test or bypass cross-origin CAPTCHA frames.

Keyboard: press i to focus the field in the embedded page, type text, then press Enter. Use Esc to leave browser input mode.

Pointer: click the embedded field or its button. The cyan focus marker must align with the control inside the frame.

Links: click the embedded navigation link. The iframe content changes without replacing this parent page. Link hints remain limited to the top-level document because Servo's offscreen JavaScript binding does not expose a child frame DOM reliably.
